\begin{center}
    \Large{\textbf{ABSTRACT}}\\
\end{center}
\vspace{1cm}

As the demand for learning Japanese continues to grow, learners often rely on separate tools such as dictionaries, flashcard applications, grammar materials, translation tools and conversation platforms. This fragmented learning process makes it difficult to track progress, review at the right time and reuse personal error data effectively. Existing tools support individual tasks well, but they remain limited in connecting learning data, personalizing review content and explaining meaning in specialized contexts.

To address this problem, the project proposes an intelligent Japanese learning system that integrates lookup, memorization, review, conversation practice and translation in a single platform. This approach was chosen because it can create a continuous learning loop, where data from dictionary lookup, flashcards, mistakes and practice sessions can be reused to support the learner more effectively.

The proposed solution includes Japanese vocabulary, kanji and grammar lookup; flashcard deck management; spaced repetition review based on the SM-2 algorithm; personalized Quiz and Story generation using flashcards, JLPT level and recent mistakes; AI Tutor conversation practice through text or speech; and specialized Japanese translation supported by a Neo4j knowledge graph combined with a large language model.

The main contribution of the project is the design and implementation of a prototype Japanese learning system that connects frontend, backend, databases and AI components in a unified product. The achieved result is a system that can help learners look up knowledge, memorize vocabulary, review, practice communication and receive intelligent feedback, forming a foundation for a more personalized foreign language learning assistant in the future.
